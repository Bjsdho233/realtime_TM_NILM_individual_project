# Tianhang's Reference Materials

本目录保留给 Tianhang 自行放入论文 PDF、讲义、网页存档、supplement 或其他
研究材料。除本说明外，目录内容默认被 Git 忽略，并视为 user-owned。

Codex 未经明确要求不得删除、改名、覆盖或重新整理这里的文件。某份材料真正
用于 review、method decision 或 dissertation citation 时，再在
[`../catalog.csv`](../catalog.csv) 登记其来源、稳定版本、用途、文件名和
SHA-256。

外部 Git repository 不放在这里；需要源码 checkout 时使用项目根目录下已忽略
的 `external/`。
